## 120 Rules grammar practice tests

English → Practice Tests now includes four parts:
- Part 1: Rules 1–30
- Part 2: Rules 31–60
- Part 3: Rules 61–90
- Part 4: Rules 91–120

Each part covers all 30 rules in a 30-question mock. The app randomises question order and answer-option order; retaking a part samples a different question for each rule from a 10-question concept pool. Because several source headings are abbreviated and multiple rules share a grammar concept, some concept pools are reused across closely related rules. Review the explanation after each answer and compare it with the uploaded PDF when a heading is ambiguous.


## 120 Rules question bank update
- Four test parts: Rules 1–30, 31–60, 61–90, and 91–120.
- Each part now generates 300 question entries (10 mapped practice items per rule), 1,200 entries total.
- Questions and answer options are shuffled for each attempt.
- Each 120 Rules part has a 60-minute timer and auto-submits at zero.
- The three uploaded grammar PDFs are the primary syllabus/rule references. Questions are authored as practice items for the site rather than copied from commercial teachers' books or paid question banks.
- Important quality note: the current generator maps each rule to a grammar-concept pool; some pool stems may recur under different rules in the same concept category. The bank has 1,200 entries but should receive a rule-by-rule editorial review before being described as 1,200 globally unique, individually authored questions.
